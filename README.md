# Tron Ares — tema para Omarchy 4

Tema oscuro comunitario para Omarchy 4 con rojo neón, negro grafito y una estética de rejilla digital inspirada en Tron: Ares.

## Instalación por CLI

```bash
omarchy theme install https://github.com/ciprianotoor/omarchy-tron-ares-theme.git
```

El instalador crea `~/.config/omarchy/themes/tron-ares` y activa el tema.
Si tu sesión no lo activa automáticamente:

```bash
omarchy theme set tron-ares
omarchy theme bg next
```

Incluye tres fondos PNG originales y sus fuentes SVG en `backgrounds/`, sin dependencias externas.

El repositorio es un tema independiente: no instala programas, fuentes ni configuraciones fuera del sistema de temas de Omarchy.
